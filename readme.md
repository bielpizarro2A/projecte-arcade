Projecte Mini Arcade

Aquest projecte és una aplicació interactiva per consola desenvolupada en Python que simula una màquina recreativa amb diferents minijocs clàssics. Disposa d'un menú principal que permet a l'usuari seleccionar a quin joc vol jugar o sortir del programa de forma senzilla.

L'arcade inclou dos jocs principals: "Pedra, Paper, Tisora" contra un robot (amb modalitats al primer que arribi a 3 victòries o al millor de 5 rondes) i el joc d'"Endevinar el Número", on el jugador ha d'encertar un número aleatori entre 1 i 100 amb l'ajuda de pistes i comptador d'intents.

Com executar el projecte
Obre la terminal a la carpeta del projecte.
Executa la comanda: python main.py
